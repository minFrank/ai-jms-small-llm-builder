## 四张数据（缺一张不发）

1. **速度**：同提示词 × 双后端 × 步数档，每格 ≥2 次取区间（写区间不写单值）
2. **资源**：内存峰值/稳态分开报、按进程名求和、减同名进程基线；磁盘递归统计
3. **真实任务**：用它给本期生成一张封面/配图，成图直接进文章；失败案例如实进「不能干什么」

## 坑（执行中累积）

- `/d/models/...` MSYS 路径 curl 写文件失败（`curl: (23) 系统找不到指定的文件`）—— 原生 curl 不认 MSYS 路径，**下载一律用 `D:/...` 风格**（2026-09-29 实测）。
- GitHub releases 下载带 `-s` 会吞掉错误 → 关键下载要 `-w` 打 HTTP 码与 size。
