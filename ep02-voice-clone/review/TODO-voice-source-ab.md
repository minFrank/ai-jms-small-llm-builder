## 怎么测（脚本已经留好）

```bash
cd ep02-voice-clone
python tools/ab_voice_source.py \
  --a "原始录音.wav"   --a-text "原始录音说的是什么.txt" \
  --b "微信语音.wav"   --b-text "微信语音说的是什么.txt" \
  --text-file story.txt
```

- 用的是**同一段**要念的文字，只有录音素材不同（这是 A/B 的关键）
- 输出到 `output/ab-<时间戳>/{a,b}/`，并打印两边墙钟耗时
- 长文本会跑很久，挑机器空闲时跑
