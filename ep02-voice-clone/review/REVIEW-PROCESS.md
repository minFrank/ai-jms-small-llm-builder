# 本地 AI 系列 · 审查流程(v2)

## 为什么要有这份文档

第 02 期第一版跑了五轮审核,每轮都能挖出新问题。归并后发现 36 条问题里,
**22% 是改稿时自己引入的**(改了数字忘了别处、删句子连带删掉整节、新增句子又带进术语黑话)。

根因不是"文章差",而是**流程缺口**:

| 缺口 | 后果 |
|---|---|
| 每轮都是"重新审一遍",不看上一轮改了什么 | 改动的副作用没人查 |
| 没有累积问题清单 | 同一类问题换个形式再犯 |
| 提示词没要求"核实上轮问题是否真修好" | 结论每轮重刷一遍 |
| 提示词没要求"日志自身自洽" | 日志里留着矛盾数据没被发现 |
| 没有"删除检查" | 改稿连带删掉整节标题都没人发现 |

## 流程(v2)

### 第 0 步:写稿

按「单期结构 v2」写:麻烦开场(前 5 段零术语)→ 明码门槛 → 三步用起来 →
实测数据 → 技术说明(标注可跳过)→ 踩坑 → 做不到什么 → 许可 → 附录。

### 第 1 步:首轮全量审(六 agent 并行)

六套提示词各自独立调用**不同模型**保证独立性。首轮**不带清单**,做全量检查。

### 第 2 步:出问题台账(关键)

把本轮 + 历史各轮的问题**归并成一份累积台账** `problems-ledger.md`:
按类别分组、标注轮次与处置。**这份台账是后续每轮的输入**。

### 第 3 步:改稿 + 记录改动清单 + **跑机械自检**(v2.1 新增)

**为什么加这一步**:第 08 期实测发现,改 9 处会带出 7 处新毛病(数字改了一处忘了另一处、
新增句子又带进黑话、同一件事反复讲)。这类问题**是机械的,不该轮到 AI 每轮再报一遍** ——
用脚本一次扫干净,又快又不会漏。

脚本:`~/AppData/Local/hermes/workspace/scripts/selfcheck_article.py`

```bash
python scripts/selfcheck_article.py articles/series/local-ai/<文章>.md
# 退出码 0 = 全绿;1 = 有机械问题
```

七项检查:

| 检查 | 抓什么 |
|---|---|
| ① 章节编号连续性 | "二"直接跳到"四"（有节被连带删掉） |
| ② 前 5 段术语闸门 | 量化/GGUF/token/权重… |
| ③ 黑话与夸大词 | 一键出片/秒出/神器/颠覆… |
| ④ 数字三处一致 | digest ↔ 正文 ↔ 图内数字 |
| **④b 口径冲突** | 同一指标出现两个值（9G 与「8G 出头」并存） |
| **④c 重复强调** | 同一件事被反复讲（「8G」出现 6 次） |
| ⑤ 重复句 | 同句在两处出现 |
| ⑥ 引用存在性 | 说"见第 X 节"但那节不存在；引用不存在的数字；图片文件缺失 |
| ⑦ frontmatter | 缺字段、引号不配对、标题超 35 字 |

**规则本身也会误报,要跟着修**:第一版把「27.9G 内存」里的 "9G" 当成了内存峰值冲突。
脚本的 pattern 要随本机实际情况调整,别为了让它绿而改文章。

### 第 4 步:改稿 + 记录改动清单(接上)

每处改动记成一行:**改了什么 → 为什么改 → 可能影响哪些上下文**。
(例:「内存 6.2→6.0」→ 影响 digest / 表格 / 图说 / 结语)

### 第 5 步:定向复验(不是重审)

把三份东西一起喂给六 agent:
1. **上一轮问题清单**
2. **本轮改动清单**
3. **累积问题台账**

提示词进入【复核模式】,输出三项:
- 上轮问题逐项核实(已修/未修/部分修 + 引用原句为证)
- 本轮改动有没有引入新问题(只看改动及其上下文)
- 台账里每一类,本轮是否又犯

### 第 6 步:收敛判断

- **阻断项归零** 且 **无「第 N 次提出」的重复困惑** → 定稿
- 否则回到第 3 步
- **不要追求"零问题"** —— 通读永远能提出新的措辞困惑。判据是:
  还有没有「数据不可信」「表述矛盾」「读者会实操卡住」这三类

## 提示词版本(v2 新增)

六套提示词都已升级到 v2,新增:

| 新增段落 | 解决什么 |
|---|---|
| 【复核模式】 | 不重审,而是核实上轮问题 + 定向复验改动 |
| 【日志自身自洽】(审查 Agent) | 抓"日志里留着矛盾数据"这类问题 |
| 【数字一致性:三处必查】(一审) | digest / 正文 / **图片** 三处数字必须一致 |
| 【口径混用】(一审) | 「模型」vs「模型+环境」、「峰值」vs「稳态」 |
| 【许可必须外部核实】(三审) | 不许想当然,必须给官方来源 |
| 【门槛必须一句话能答】(三审) | 读者不用自己权衡几个数字 |
| 【删除检查】(校对) | 小节连续性 / 被引用不存在的数字 / 重复段落 |
| 【第 N 次提出】标注 + 实操卡点优先(通读) | 反复出现的困惑要升级处理 |

后台可版本回滚(`POST /api/prompts/{key}/rollback`)。

## 适用范围

本流程**同样适用于其他栏目**(AI 雷达 / 码上趋势 / 财经周报 / 每日精选),
只需把提示词的 scope 换成对应栏目 —— 复核模式与删除检查是通用的。
