# ep02 · 用你自己的声音念文字(本地一键包)

第 02 期:让电脑用**你自己的声音**把文字念出来。全程离线、免费、开源。

配套文章:《孩子睡前要听你的声音,可你还没到家》

## 三步用起来(两次双击)

1. 双击 **一键安装.bat** —— 只需一次,自动下载运行环境与模型（合计约 7–12G，看下载源）
2. 往本文件夹放三样东西:

   | 放什么 | 是什么 |
   |---|---|
   | `我的录音.wav` | 手机自带录音机录 20–30 秒(别用微信语音,压缩太狠) |
   | `我的录音说的是什么.txt` | 录音里**实际念的那句话**,一字不差 |
   | `story.txt` | 你要它念的文字 |

3. 双击 **一键生成.bat** —— 结果在 `output\故事.mp3`

原始日志见 `logs/run-2026-09-13.md`(含四次运行),上面每个数字都能指到具体行。

**可移植性 + 双入口**:本包在 `local-voice-kit` 与 `ep02-voice-clone` 两处都真跑通过;中文入口(`一键生成.bat`)与英文入口(`start.bat`)也各真跑过一次 —— 脚本用 `__file__` / `%~dp0` 自定位,换目录不受影响。

## 它做不到什么

- 不会"演"情绪,只能准确念字
- 多音字会念错(在 story.txt 里改写成同音字绕开)
- 吃内存,跑的时候别开大型软件
- 录音素材决定一半成败:微信语音当素材必然发闷
- 慢:5.6–6.8 倍实时

## 这个包里修掉的坑(都在 tools/tts.py 注释里)

1. **长文本被引擎切成多段,默认只输出第一段** → 成品可能只剩开头(实测只剩 15.84 秒)。包内自动拼接。
2. **chdir 之后相对路径失效** → `LibsndfileError: Error opening '…\CosyVoice\我的录音.wav'`。包内先绝对化路径。
3. **CPU 上权重需转 float32**,否则 `mat1 and mat2 must have the same dtype`。
4. **参考文本必须带前缀** `You are a helpful assistant.<|endofprompt|>`,否则引擎崩。
5. **.bat 的 if 块内不能有半角括号** → cmd 报 `。 was unexpected at this time.`,提示文字一律用全角。
