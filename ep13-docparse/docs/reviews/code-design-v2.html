1. 第一层 · 协议 A 显式状态机（重写 r1 伪代码）

权威源 §2.2（F-01/X-01）：target_valid=6；initial_max_attempts=8；IQR/median>10% → 扩展至 12；12 次有效仍>10% → unstable；n_valid<4 → failed；4≤n_valid<6 → partial；median≤0 → 报错；max_attempts 硬终止。
class CellRunner:                       # C-01/C-02/C-03 修复
    n_attempt = 0;  n_valid = 0        # ★两个计数分离——失败/超时也占 attempt
    max_attempts = 8;  extension = False
    walls = [];  reps = [];  fatal = None

    def run(self):
        while True:                     # 出口只有三个，全失败也必出
            if fatal: break             # ① CellFatal
            if n_attempt >= max_attempts: break   # ② 硬终止（8 或 12）
            n_attempt += 1
            rep = worker.infer(timeout=T_INFER)    # 父进程计时，超时 kill+respawn(§5)
            reps.append(rep)            # status ∈ ok|fail|timeout|skipped 全入账
            if rep.ok:
                n_valid += 1; walls.append(rep.wall)
            # —— 扩展触发（C-01 修复：8→12 显式两阶段）——
            if (not extension and n_attempt >= 8
                    and n_valid >= 6 and iqr_over(walls)):
                extension = True;  max_attempts = 12   # 触发后继续跑到 12
            # —— 达标即停 ——
            if n_valid >= 6 and not iqr_over(walls): break
        return self.finish()

    def finish(self):                   # C-03 四种收尾（规格 §2.2 原文）
        if fatal:                return status="failed",  err_kind=fatal
        if n_valid < 4:          return status="failed"
        if 4 <= n_valid < 6:     return status="partial"        # 进分母、不进名次、单列
        if median(walls) <= 0:   return status="failed", err="median_le_0"   # 报错留痕
        if iqr_over(walls):      return status="complete", unstable=True    # 12 次仍不稳：只报分布不排名
        return status="complete"

    # 单测三例（dsh 要求）：① 6 次达标即停 ② 8 次仍超阈→max=12 继续 ③ 12 次仍超阈→unstable
C-xxv2 修复
C-01 死分支8→12 由 extension 显式触发后 max_attempts 变 12 继续跑，删除不可达分支
C-02 valid当attemptn_attempt 每轮先 +1；失败/超时入 reps 占 attempt；三出口保证全失败不死循环
C-03 四收尾缺失finish() 逐条实现 failed/partial/unstable/median≤0；status 严格四态 complete|partial|failed|skipped
C-05 控制在格中rep 循环内零控制检查；控制检查移到 cell save 之后的格边界（§5 伪代码）
C-06 心跳独立心跳进程每 5s 原子写 control/task.json（tmp+rename），与推理解耦；stale=连续15s 无心跳且owner_pid 死亡；pid 活着标 stalled 不判死
