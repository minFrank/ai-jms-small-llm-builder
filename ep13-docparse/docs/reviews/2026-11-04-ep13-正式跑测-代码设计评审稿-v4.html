2.1 CellRunner 状态机（R2-01 接线版）

INIT建 Cell 累加器 → RUNNINGn_attempt+1 → infer(timeout=1800s) → RECORDEDrep 入 reps[]；ok→n_valid+1,walls/cers 追加 → EVAL见 2.2 判定树 ↻ RUNNING未达出口且 attempt<max
EXTENDINGattempt≥8 且 n_valid≥6 且 IQR>10% → max=12 → DONE-completen_valid≥6 且 IQR 合格 | DONE-complete+unstableattempt=12 且仍超阈 | DONE-partial4≤n_valid<6 | DONE-failedfatal / n_valid<4 / median≤0 
# R2-01 接线 v4（r3 阻断2 修复：单点计数/实例化/timeout/return）
class Cell:                      # 累加器 = schema 的生产者
    def __init__(self, **kw):    # 实例属性（修类属性共享坑）
        self.reps = [];  self.walls = [];  self.cers = []
        self.n_attempt = 0;  self.n_valid = 0;  self.fatal = None
        ...
    def absorb(self, rep):       # ★ n_attempt 只在这里 +1（单点计数）
        self.reps.append(rep);  self.n_attempt += 1
        if rep.status == "ok":
            self.n_valid += 1; self.walls.append(rep.wall); self.cers.append(rep.cer)
    def to_schema(self):         # fill required 19 + 聚合；空 walls→median=null
        ... n_fail=n_attempt-n_valid; wall_median/iqr（walls 空→null）; cer_median;
           cell_success_rate（n_attempt=0→null）; trunc_rate; unstable; err_kind...

def run(cell, worker) -> Cell:  # ★ 返回 cell（落盘契约统一）
    try:
        while True:
            if cell.fatal: break
            if cell.n_attempt >= cell.max_attempts: break
            try:
                rep = worker.infer(timeout=1800)
            except TimeoutError:
                rep = Rep(status="timeout", ...)      # ★ 超时也产 rep（占 attempt）
            except CellFatal as e:
                cell.fatal = e.kind;  break           # 不 absorb，走 finally
            except WorkerFatal:
                respawn_or_mark();  continue          # ★ 先 respawn/重试，不落 absorb(rep)
            cell.absorb(rep)
            if extension_gate(cell): cell.max_attempts = 12
            if done_ok(cell): break
    finally:
        cell.finish()             # 2.2 判定树（含空 walls→failed）
        save_raw(cell); validate_soft(cell)   # F-05
    return cell                   # ★

7. 进程与控制 v3

  • 单写者（R2-09）：runner 独占 control/task.json（state/seq/ack/lease/last_progress/updated_by）；心跳进程只写 control/heartbeat.json；外部 UI 只写 desired_state（经 API 落 task 的 desired 字段由 runner 收编）；任何写=tmp+rename；lease TTL 60s 由 runner 续（renewed_at）。
