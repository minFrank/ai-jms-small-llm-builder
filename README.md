# ai-jms-small-llm-builder

「本地无显卡 AI」系列 —— **小模型本地实测代码仓库**。

对应公众号「AI 积木师」的本地 AI 栏目。每一期一个独立目录,代码、原始日志、复刻说明都在里面。

## 目录规范

```
epNN-<主题>/            ← 每期一个目录,NN 为期号(两位)
    ├─ README.md        ← 本期要做的事 + 实测数据 + 数字溯源自查
    ├─ logs/            ← 原始运行日志,文章里每个数字都要能指到这里某一行
    ├─ tools/           ← 本期脚本(带注释)
    └─ …                ← 一键包 / 命令 / 素材模板
```

期号与公众号发布的期号一致。

## 每期的硬规矩

这几条是这个仓库存在的意义,**缺一条就不该发**:

1. **数据必须来自本机实测。** 不做搬运工 —— 别人测的、推测的、厂商给的数字都不算。
2. **四样数据必须有**:速度 / 资源占用 / 真实任务效果(含**失败案例**)/ 门槛(下载体积分级 + 要不要显卡)。
3. **数字可溯源。** 文章里的每个数字,都要能在本期 `logs/` 里指到具体一行;指不到就改稿。
4. **门槛明说。** 内存不够、显卡不够、下载太大,直接劝退,不藏着。
5. **绝对不推收费模型。** 出现需要付费或注册才能用的,本期作废。免费额度、试用钩子一概不出现。
6. **许可写清楚。** 尤其"能不能商用"——要对外发布的场景不能有授权风险。
7. **失败要写。** 踩到的坑比顺手的部分更有价值,而且往往是只有真跑才会暴露的。
